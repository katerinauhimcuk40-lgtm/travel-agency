# TravelAgency

Інформаційна система туристичної фірми — навчальний проєкт з дисципліни
«Конструювання програмного забезпечення» .

Студентка: Юхимчук К.О., група ІПЗ-32.

## Технології

- C# / .NET 8+ — ASP.NET Core Web API
- Entity Framework Core + MySQL 8 (InnoDB)
- xUnit — тестування
- Docker / docker-compose — середовище розробки
- GitHub Actions — CI

## Структура репозиторію

```
src/      вихідний код (Core, Infrastructure, Api)
tests/    автоматизовані тести
docs/     документація (аналіз вимог, проєктування, звіти)
```

## Робота з git

- `main` — стабільна гілка, лише через злиття готових гілок (pull request)
- `docs/<назва>` — документація
- `feature/<назва>` — нова функціональність
- `test/<назва>` — тести
- Повідомлення комітів — за Conventional Commits (`feat:`, `docs:`, `test:`, `chore:`)
